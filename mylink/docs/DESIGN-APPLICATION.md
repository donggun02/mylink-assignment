# MyLink 디자인 적용 메모

원본: https://getdesign.kr/services/toss/llms.txt
수집일: 2026-11-12. docs/DESIGN.md는 카탈로그의 토스 문서 원문입니다. 카탈로그는 공식 토스 제품 자체가 아니라 공개 자료 기반의 디자인 정리입니다.

- 최종 화면은 Profile 컴포넌트의 DOM·내용·배치를 유지하고 .toss 스타일로 색·서체·간격·라운드를 변경합니다.
- #3182F6 단일 강조색, #191F28 본문, #4E5968 보조 본문, #F2F4F6 보조 표면, #F9FAFB 페이지 바탕.
- 주요 파란색 채움 링크는 GitHub 하나. 다른 링크는 회색 보조 액션.
- 무료 대체 서체 Pretendard, 미지원 시 OS 고딕. TPS는 재배포하지 않음.
- 본문15px/1.5, 제목28px/700, 링크17px/700, 4px 단위 여백, 카드24px/버튼16px 라운드.
- 기본 카드 그림자는 제거하고 1px 헤어라인으로 구분.
- 과제의 반응형 비교를 유지하기 위해 360/768/1024 분기를 사용합니다. 토스 공식 breakpoint라는 뜻은 아닙니다.
- 자기소개는 3주차에서 확정한 문구를 보존합니다. 시스템 UI는 해요체를 사용합니다.

## 적용 프롬프트
docs/DESIGN.md 파일을 읽고, 그 디자인 규칙에 맞춰 프로필 페이지를 다시 스타일링해줘. 기존 레이아웃 구조는 그대로 두고 색상·글꼴·간격·모서리만 바꿔줘.
