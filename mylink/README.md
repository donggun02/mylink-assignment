# MyLink

김동건의 프로필과 링크 모음. Next.js App Router 기반 4주차 실습입니다.

## 실행

이 폴더에서 `npm ci` 후 `npm run dev`를 실행하고 http://localhost:3000 에 접속합니다.

파일 감시 한도 오류가 나면 `WATCHPACK_POLLING=true npm run dev -- --webpack`을 사용합니다.

## 화면

- `/`: docs/DESIGN.md 기반 최종 화면
- `/practice/bad`: 막연한 프롬프트로 제작한 첫 화면
- `/practice/neo`: 구체적인 Neobrutalism 프롬프트 화면

실습 기록은 docs/WEEK04.md, 디자인 적용 설명은 docs/DESIGN-APPLICATION.md에 있습니다.

기존 index.html은 GitHub Pages용으로 보존되어 있습니다. GitHub Pages는 Next.js 소스를 실행하지 않으므로 현재 공개 주소와 localhost의 최종 화면은 다를 수 있습니다. 최종 Next.js 배포는 이후 배포 주차에서 진행합니다.
