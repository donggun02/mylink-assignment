# MyLink

개인 크리에이터와 일반 사용자를 위한 멀티 링크·바이오 프로필 서비스입니다.

## 실행

```bash
cd mylink
npm ci
WATCHPACK_POLLING=true npm run dev -- --webpack
```

http://localhost:3000 에서 확인할 수 있습니다.

## 기능

- 프로필 이름·소개·이미지 편집, 소셜 배지 관리
- URL 링크와 섹션 추가·수정·삭제, 공개 여부 설정
- 손잡이 드래그 정렬과 키보드·모바일용 위/아래 이동
- 모바일 목업 실시간 미리보기
- 블루 TDS·다크·페스티벌 테마
- 브라우저 내 방문자·링크별 클릭·최근 7일 추이
- LocalStorage 자동 저장 및 다른 탭 변경 반영
- 프로필 사본 공유 주소 복사

## 페이지

- `/`, `/mypage`: 편집기
- `/view`: 같은 브라우저에 저장된 공개 프로필
- `/view#profile=…`: 주소에 포함된 공유 시점의 프로필 사본

## 데이터와 공유

별도 서버·계정·인증 없이 작동하는 클라이언트 데모입니다. 데이터는 현재 브라우저에만 저장됩니다. 브라우저 데이터를 지우면 편집 내용과 통계도 삭제됩니다.

통계의 방문자는 현재 브라우저 식별자 기준입니다. 방문 추이는 탭 세션당 하루 한 번 기록하며, 링크와 소셜 배지는 클릭할 때마다 집계합니다. 편집기 미리보기는 집계하지 않습니다. 삭제한 링크의 과거 클릭도 누적 합계에는 포함됩니다.

공유 주소는 서버에 프로필을 등록하는 대신 이름·소개·링크·테마의 사본을 주소에 담습니다. 수정 후에는 새 주소를 복사해야 합니다. 업로드 이미지는 공유 사본에서 기본 아바타로 대체됩니다. 다른 기기의 방문·클릭이나 공유 사본의 활동은 편집기 통계로 합산되지 않습니다. localhost 주소는 현재 컴퓨터에서만 접속할 수 있고, 외부 공유에는 호스팅이 필요합니다.

이미지는 PNG·JPG·WebP 800KB 이하로 업로드할 수 있습니다. 링크는 HTTP·HTTPS 주소만 허용합니다.

## 구조

- `mylink/src/app`: Next.js App Router 페이지
- `mylink/src/components`: 프로필 UI
- `mylink/public`: 이미지와 서체
- `mylink/docs/DESIGN.md`: 참고 디자인 규칙

기존 `mylink/index.html`은 GitHub Pages용 정적 페이지입니다. Next.js 앱과 별도로 동작합니다.
